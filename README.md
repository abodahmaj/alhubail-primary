# ابتدائية الحبيل

واجهة عربية متجاوبة لرصد الدرجات وتحليل التحصيل الدراسي.

صمم بواسطة أ. أفراح عسيري

## حالة النسخة
معاينة واجهة فقط. تسجيل الدخول والحفظ غير مفعّلين، ولا يتضمن هذا المستودع بيانات طلاب أو هويات أو كلمات مرور أو اتصالًا بقاعدة البيانات.

GitHub Pages: https://abodahmaj.github.io/alhubail-primary/

## التشغيل المحلي
```sh
python -m http.server 8317
```

## التحقق
`test_ui.py` يستخدم Playwright وChrome لاختبار المقاسات والتنقل. مخرجات الاختبارات محلية وغير منشورة.
